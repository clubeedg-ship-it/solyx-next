# Solyx — status, 25 August 2026

## Live now

**The website is live and clean.** www.solyxenergy.nl answers 200, staging at
2026.solyxenergy.nl answers 200. The August work closed out the migration:
analytics on GTM behind Google Consent Mode, the commerce funnel measured for
both Meta and Tag Manager, a verified 301 table, the privacy policy published,
every mobile overflow cleared, every dead link repaired, and the last dependency
on the legacy domain cut.

**The content assistant is running.** solyx.oopuo.nl, deployed 19 August. It is
a chat where a change to the site is asked for in plain language instead of
being done by hand in WordPress. Around it: threads that keep their history,
titles generated from the first message, a drafts panel reading live from
WordPress, draft previews, and a browser that shows every published page as a
card with a rendered thumbnail.

**Safety, as it stands today.** The assistant edits text only. Audited: it
cannot delete a page, cannot touch a page that is already published, cannot
change a setting.

## Today

Connected the assistant to the agent runtime and verified the connection
end to end. Corrected project documentation that was making false claims about
where things live. All 314 automated tests green.

## Next

The assistant graduates from editing words to building pages. It will compose a
page from the site's existing design blocks rather than only changing the text
inside blocks someone else placed.

The safety guarantee moves rather than disappears. Everything it builds is a
draft, and it is structurally incapable of publishing. WordPress itself denies
it the permission, so this is a locked door rather than a promise. Approval
stays human. No delete, no settings, unchanged.
